# Changelog

## 1.1.0 - 2026
- Operating mode filter (CW / DATA / PHONE) in the Change Location tool, applied to both the map and the list.

## 1.0.0 - 2026
- Initial release: live POTA spots on a Leaflet / Esri dark map, with a table of callsigns below.
- Change Location tool: state dropdown or browser location.
- On Air / QRT status with 20 minute QRT retention.
- Overlap handling: QRT spots yield to On Air spots; crowded spots and multi-callsign parks are grouped into tables with leader lines.
- Per-park colors for parks sharing a table.
- Compass rose header icon; layout and palette based on the ADS-B radar page.
